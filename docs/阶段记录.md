# 股票趋势分析项目阶段记录

> 本文件记录实际进展。任务只有取得对应验收证据后才能标记为“已完成”；计划中的工作保持“待开始”。每次执行在文末追加日志，保留原有记录。

## 一、项目目标与约束

- **目标**：完成一个本地学习演示项目，支持 A 股和美股的在线日线采集、存储、指标计算、趋势评分和历史结果查询。
- **首版范围**：先建设并验收后端；课堂前端截图只用于理解操作流程和接口所需数据。
- **实现约束**：沿用 `routers → service → repository` 分层。数据库、Redis、行情接口等 I/O 密集型任务必须使用异步接口；纯指标计算保持普通函数。
- **数据约束**：在线来源失败时明确报错，不以模拟数据冒充真实行情；分析结果应标明数据日期、来源和规则版本。
- **仓库约束**：新增或修改 `app/models/` 下的数据库模型前，须按 [AGENTS.md](../AGENTS.md) 取得明确人工确认。

### 当前工程基线

已存在 FastAPI 应用入口、`/health`、`/`、配置、异步 MySQL 会话、Redis 生命周期、统一错误响应、日志、测试和 CI。纯计算的 MA、RSI、MACD 与趋势评分规则已实现；四张业务表及股票归档字段均已在本地 MySQL 学习库中建表或迁移。四个模型现有三组双向 ORM 关系，均禁止隐式懒加载。股票新增、列表、归档、恢复、在线日线采集、候选搜索、已存日线查询及 `/` 均已通过自动检查和用户手动复验。采集接口现已改为调整后价格；学习库旧的 92 条未调整日线已清理。用户已对另外两只股票完成新口径的首次采集、查询和重复采集复验。发起趋势分析、逐日结果查询及批次列表查询均已通过自动检查和用户复验。
