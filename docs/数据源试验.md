# T-01：A 股与美股在线日线数据源试验

试验日期：2026-11-13。本文记录本机实际发起的在线请求及其结果，行情数值仅用于验证数据接口，不构成投资判断。课堂资料和前端截图是需求参考，股票身份及接口行为以实际数据和来源文档核对。

## 给初学者的跟做步骤

T-01 的实际取样已经完成。下面是帮助你**亲眼看懂一次取样**的小练习，不需要先学数据库、爬虫或股票指标。先做第 1、2 步；理解返回内容后，再做第 3 步。

1. **在浏览器看美股响应。**打开 [AAPL 的五条日线示例](https://api.twelvedata.com/time_series?symbol=AAPL&interval=1day&outputsize=5&adjust=none&apikey=demo)。这是向数据网站发送一次 `GET` 请求。找到 `meta.symbol`，它应是 `AAPL`；再找到 `values`，它是多条日线组成的列表。每条记录的 `datetime` 是交易日期，`open/high/low/close/volume` 分别是开盘、最高、最低、收盘、成交量。实时结果的日期和价格会变化，重点看字段结构。
2. **在浏览器看 A 股响应。**打开 [复旦微电的腾讯日线示例](https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh688385%2Cday%2C%2C%2C5%2C)。找到 `data → sh688385 → day`。其中一行看起来像 `["日期", "开盘", "收盘", "最高", "最低", "成交量", …]`。注意腾讯把**收盘放在最高前面**。页面最后一行可能是当天尚未收盘的数据，不能直接当成最终日线入库。
3. **再用异步 Python 发起美股请求。**在编辑器中打开 `D:\project\mock_stock_trend`，在项目根目录新建临时文件 `t01_probe.py`，粘贴下面的代码。在 PowerShell 中依次运行 `cd D:\project\mock_stock_trend` 和 `.venv\Scripts\python t01_probe.py`。看到 `状态码: 200`、`股票: AAPL` 和一条包含日期、开高低收量的记录，就完成了这个练习。这个临时文件只用于学习，不属于 `app/` 的业务实现。

   ```python
   import asyncio

   import httpx


   async def main() -> None:
       async with httpx.AsyncClient(timeout=15) as client:
           response = await client.get(
               "https://api.twelvedata.com/time_series",
               params={
                   "symbol": "AAPL",
                   "interval": "1day",
                   "outputsize": 5,
                   "adjust": "none",
                   "apikey": "demo",
               },
           )

       print("状态码:", response.status_code)
       data = response.json()
       if "values" not in data:
           print("接口返回错误:", data)
           return
       print("股票:", data["meta"]["symbol"])
       print("最新一条日线:", data["values"][0])


   asyncio.run(main())
   ```

这里 `async def` 定义异步函数，`await client.get(...)` 等待网络返回，`asyncio.run(main())` 启动这个小程序。`response.json()` 只是把收到的 JSON 转成 Python 字典。若出现超时或连接错误，先检查网络；这不代表你写错了股票指标。做完后，试着用自己的话说出“请求哪只股票、从哪里看日期、从哪里看收盘价”即可。

## 试验方法与验收

使用虚拟环境中的 `httpx.AsyncClient` 发起异步 HTTPS 请求；本卡没有把课堂示例中的同步 `requests`、`akshare` 或 `yfinance` 调用放进项目的异步请求链。核对 HTTP 响应、交易日、开高低收、成交量、可取得的历史条数，以及异常时的响应。没有新增业务代码、数据库模型或公开 API。

验收条件是 A 股、美股各取得一份真实日线样本，且至少检查日期、OHLC 关系和成交量。两份样本均已取得，T-01 的**数据源试验**已完成；生产接入和任意美股代码的密钥验证仍属于后续工作。

### A 股请求与字段

实际可用的上游为 `https://proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get`，以 `sh688385` 和 `sz000001` 分别取得沪市、深市样本。请求参数采用 AKShare 当前实现中的 `_var=kline_day2026`、`param=sh688385,day,2026-01-01,2026-12-31,640,` 等格式；响应正文带有 JavaScript 变量前缀，需要先提取 JSON。该接口没有面向本项目的稳定公开契约，日后应封装在独立的数据源适配器中。[AKShare 的腾讯接口实现](https://github.com/akfamily/akshare/blob/main/akshare/stock/quote/stock_hist_tx.py)。

腾讯原始数组前六项依次是 **日期、开盘、收盘、最高、最低、成交量**；不能按常见的“日期、开盘、最高、最低、收盘、成交量”顺序读取。成交量原始单位随证券类型变化：`sh688`、`sh689` 按股；其他已列出的市场类型按手，换算为股时乘以 100。试验中的 `sz000001` 原始成交量为 `1,082,721` 手，对应 `108,272,100` 股。[AKShare 字段选择与成交量换算源码](https://github.com/akfamily/akshare/blob/main/akshare/index/index_stock_zh.py)。

试验旧版 `fqkline/get` 地址时，`sh688385` 的最后一条为试验当天 `2026-11-13`，可能是尚未收盘的日线；本次样本选用前一个交易日 `2026-11-12`，且与当前 `newfqkline/get` 返回的最后一条一致。实际入库前必须判断日线是否已完成，并按请求日期范围过滤上游结果。一次请求可能达到条数上限，历史回补需要分页、去重与排序。

### 美股请求与字段

实际请求 `https://api.twelvedata.com/time_series`，参数为 `symbol=AAPL`、`interval=1day`、`outputsize=90`、`adjust=none`、`apikey=demo`。响应的 `values` 按日期倒序，字段是 `datetime/open/high/low/close/volume`，数值以字符串表示。后续转换时应使用十进制数并按交易日升序排列。官方文档说明 `outputsize` 上限为 5000，且不显式指定 `adjust` 时默认采用拆股调整，因此请求必须明确写出调整口径。[Twelve Data 时序接口文档](https://twelvedata.com/docs/market-data/time-series)。

演示密钥只验证了 AAPL。用相同演示密钥请求 `MSFT` 时，接口返回 HTTP 401，明确要求申请个人密钥。因此，**不能把 `demo` 当作任意美股代码的正式接入方案**。后续接入前需要用用户自己的密钥验证目标代码、请求额度及使用条款；密钥只能从环境变量读取。Twelve Data 的[股票数据页面](https://twelvedata.com/stocks)说明免费层覆盖美股，国际市场权限依方案而异。

## 代码与名称核对

课堂截图中的 `688825.SS` 被标为“复旦微电”。[上交所公告](https://www.sse.com.cn/disclosure/announcement/listing/ipo/c/c_20210803_82476092.shtml)明确复旦微电代码为 `688385`；[上市披露文件](https://static.cninfo.com.cn/finalpage/2026-08-27/1225514122.PDF)显示 `688825` 为长鑫科技。`688825` 试验只返回自 2026-07-27 起约 74 条日线，与其上市时间相符。截图中的代码和名称不能直接作为种子数据。新增股票时要核对市场、代码、名称，并以代码与市场组合作为唯一身份。

## 给后续开发的输入

1. 先定义统一日线字段：市场、标准化股票代码、交易日、开高低收、**股数**、币种、来源、价格调整口径和获取时间；不要直接把上游 JSON 或数组存入数据库。
2. 纯字段解析和校验可用普通函数；网络请求必须保持异步。错误要区分 HTTP 失败、非预期响应、空数据、代码不存在和未收盘日线。
3. 当前 A 股候选是腾讯证券上游的异步 HTTP 适配；美股候选是 Twelve Data 官方 API。美股接入任意代码前，必须先用个人密钥重新验收。
4. 下一张计算规则卡需要明确价格调整口径：本次只验证了未复权或 `adjust=none` 的取样方式，尚未决定用于长期趋势分析的最终口径。不同来源或不同调整口径的数据不能混合计算。
