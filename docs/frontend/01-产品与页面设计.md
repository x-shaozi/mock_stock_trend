# Stock Trend Lab：产品与页面设计（确认版 V1）

## 定位
个人股票追踪与历史日线趋势分析平台，不是实时交易终端，不提供下单或分钟 K 线。

## 已决定的视觉规范
- 浅色 / 深色 / 跟随系统三态切换，偏好保存在浏览器本地；首访默认跟随系统。
- 桌面优先，兼顾移动屏幕；主导航 + 顶部工具栏 + 内容区。
- 用 CSS 变量统一页面、Element Plus 和未来 ECharts 的配色。
- 涨跌颜色按市场习惯做配置，不在 K 线组件中写死；历史数据不标为实时行情。
- 行情数字在表格中右对齐，价格精度、缺失值和数据口径清晰显示。

## 页面路线
| 路由 | 阶段 | 功能 |
|---|---|---|
| `/stocks` | S1 | 本地股票列表、状态、市场、关键词、分页 |
| `/stocks/add` | S1 | 外部候选搜索、选中登记 |
| `/stocks/archived` | S1 | 已归档列表、恢复 |
| `/stocks/:stockId` | S2 | 独立详情、日线采集、OHLC K 线、成交量 |
| `/stocks/:stockId/analysis/:runId` | S3 | 保存的分析批次及逐日结果 |

## 数据展示注意事项
- 详情使用 P1 `GET /stocks/{stock_id}`，归档股票可查看历史。
- 读取日线和联网采集分开；采集后主动重新请求日线。
- 价格 JSON 是 Decimal 字符串，交易日使用 `YYYY-MM-DD`，不做 UTC 换算。
- RSI14 使用后端 v1 口径；MACD 当前为 DIF−DEA 不乘 2；完整 DIF 和 DEA 曲线未由现有 API 提供，不假装存在。
- 未计算出的指标显示空值，不显示为 0；旧分析快照必须标注计算时间。
- 只有后端确认的新分析才更新趋势评分；不在 Vue 中重复实现指标规则。

## 无数据和错误交互
- 无股票：引导添加股票。
- 无行情：引导采集日线。
- 409 STOCK_ALREADY_EXISTS：提示已存在；409 STOCK_ARCHIVED：提示恢复或只读。
- 409 INSUFFICIENT_HISTORY：建议采集更多完整交易日。
- 409 PRICE_BASIS_CONFLICT：显示不能混合不同数据口径。
- 502 外部依赖错误：可重试，但不得伪装成功。
- 422：显示字段校验信息；网络错误：给出重试入口。

## 暂不实施
市场总览聚合大屏、实时 WebSocket、登录注册、个人资产组合与自动交易；未来公网用户功能必须后端先实现相应安全边界。
