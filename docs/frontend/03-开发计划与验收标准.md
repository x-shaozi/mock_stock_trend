# Stock Trend Lab：分阶段开发与验收标准

## S0 工程初始化（本地检查已执行）
- 放置 `frontend/`，初始化 Vue 3 + TS + Vite + Router + Pinia + Element Plus。
- 配置 Axios 统一异常处理、Vite `/api` 开发代理、三态主题与占位路由。
- 配置 OpenAPI 生成、ESLint、Prettier、vue-tsc、Vitest，编写初始错误契约单元测试。
- **2026-11-15 本地结果**：pnpm 10.0.0 安装及锁文件重复安装通过；OpenAPI 类型生成、lint、typecheck、3 个 Vitest 测试、format:check、build 通过。lint 仍有 21 条排版警告，构建仍有首包体积警告。
- **浏览器结果**：`/api/health` 返回 200；占位路由、刷新、未知路径提示、浅色和深色主题及刷新记忆、窄屏无横向溢出均已检查；主题已恢复为“跟随系统”。
- **待完成**：用户手动复核，以及前端文件推送后确认 GitHub CI 运行通过。浏览器测试未覆盖操作系统主题变化和后端断开时的提示。

## S1 股票追踪
- `/stocks`: `GET /stocks` 全条件分页；`/stocks/add`: `GET /stocks/search` + `POST /stocks`；`/stocks/archived`: 归档恢复。
- 验收：成功、空值、越界分页、外部 502、重复 409、归档 409、422 校验均正确显示；URL 刷新保留必要参数。

## S2 日线行情
- `/stocks/:stockId`：P1 股票详情与 `GET /prices`、`POST /prices/collect`；真实 ECharts OHLC + 成交量。
- 验收：行情价格字符串适配、排序、空图、采集后重新拉取、来源/复权/币种标注均正确。

## S3 趋势指标与历史快照
- 分析运行：`POST /analysis-runs`；历史列表：GET 同路径；详情 `GET /analysis-runs/{runId}`。
- 验收：35～260 条日线条件、同条件 201/200、前 34 条预热空值、MA5/MA20/RSI14/MACD、规则版本与计算时间正确显示；不重算后端规则。

## S4 工程及部署验收

- 单独门槛：完成后端认证权限、限流、第三方行情公开授权后，才能开放公网业务访问。
