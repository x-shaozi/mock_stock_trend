# Stock Trend Lab：前端技术架构（S0）

## API 契约
以根目录 `docs/openapi.yaml` 为唯一公开接口契约来源，生成类型到 `frontend/src/api/generated/schema.d.ts`。用户报告后端已通过 166/166 测试，覆盖率 91%，Ruff、OpenAPI 一致性与 Python 3.11/3.14 CI 均通过；本交付没有重新运行这些后端检查。

## 技术选择
Vue 3 + TypeScript + Vite；Vue Router；Element Plus；ECharts（在 S2 首次实际使用）；Pinia（只在确有跨页共享状态时使用）；Axios；openapi-typescript；Vitest；ESLint + Prettier + vue-tsc。为了避免过度设计，初期不引入微前端、SSR、复杂服务端状态缓存。

## 项目边界
```
浏览器 View → 组件/Composable → 前端 API → Axios → /api/*
开发：Vite proxy → FastAPI 127.0.0.1:18000
生产：Nginx proxy → FastAPI 内网监听端口
FastAPI Router → Service → Repository → MySQL
```

## 数据规范
- `api/` 仅负责通信、解析错误；`features/` 后续按 stocks/prices/analysis 分别组织领域页面和组件。
- `schema.d.ts` 从契约生成，不手写后端模型。价格原值保留字符串，绘图时单独转换 Number 并检查有限性。
- 交易日是交易所本地日历日期；`computed_at` 是 UTC 时间点，进入 UI 时再转换本地时区。
- 趋势批次历史数据与当前行情独立展示。禁止将已保存的批次伪装为最新实时结果。

## 深浅色切换
- Element Plus 官方的 `html.dark` CSS 变量机制；`src/composables/useTheme.ts` 维护 `light/dark/system` 三态。
- 主题选择持久化到 localStorage；`system` 模式监听 `prefers-color-scheme` 变化。
- ECharts 在 S2 通过显式主题色映射或 setOption 同步刷新；不要假设只切换 CSS 即可更改 canvas 内颜色。

## 安全
- 不在 `VITE_*` 中放置密钥：其值在构建后对浏览器可见。
- 当前尚无完整公网登录/授权限流方案，所以开发版只用于本地/受控环境。
- 公网发布需单独完成 P0 安全任务与数据展示授权，前端不能替代后端权限控制。

## 兼容契约验收
- `GET /stocks` 支持 status、market、keyword、page、page_size；详情 `GET /stocks/{id}`。
- 业务错误响应包含可选 error_code；通用 422/500 等不强制拥有业务标识。
- `GET /health` 返回 `{"status":"ok"}`，仅验证 HTTP 进程。
