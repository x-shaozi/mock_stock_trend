# T-02：趋势计算规则 v1

本卡只固定纯计算规则，不采集行情、不访问数据库，也不新增 API。实现位于 [`app/service/analysis_rules.py`](../app/service/analysis_rules.py)，固定样本位于 [`tests/test_analysis_rules.py`](../tests/test_analysis_rules.py)。`v1` 是教学演示用的规则版本，分数表示这些条件的合计结果，不是股价预测。

## 先理解输入

指标计算函数接收一串**按交易日从早到晚排列、已经收盘、价格口径一致**的收盘价。例如 `[100, 102, 101, 105, 108]` 的最后一天收盘价为 108。函数只接收价格，所以排序、去重、排除未收盘日线和标记来源，需要后续的数据源适配层保证。

**分析天数决定计算输入。**例如数据库已有 100 条日线，用户请求分析 90 天，就只取最近 90 条已完成日线，从这 90 条的第一天开始计算；不是取 100 条计算后只展示 90 条。请求 90 天和 100 天可能得到不同的 MACD 与评分，这属于不同输入产生的正常结果。结果入库时必须标明它属于哪一次、哪段日期的分析，避免互相覆盖。当前分析接口要求至少 35 条，并且库中要有请求指定的完整条数；不够时返回 409 和现有条数，不会悄悄缩小计算范围。

本版约定使用**调整后收盘价**计算趋势：A 股请求腾讯前复权 `qfq`，美股请求 Twelve Data 的 `adjust=all`。2026-11-13 的在线试验中，腾讯前复权改变了复旦微电较早的价格、保持最近价格不变；Twelve Data 的 `all` 调整了 AAPL 在 2020 年拆股前的价格与成交量。两者的公司行动处理并非完全相同，数据来源、调整参数和规则版本必须随分析结果一起记录；不能把未复权与调整后价格混进同一条序列。[AKShare 复权说明](https://akshare.akfamily.xyz/data/stock/stock_quote.html)、[Twelve Data 参数说明](https://twelvedata.com/docs/market-data/time-series)。

当前纯计算代码**不会自行检查价格是否已复权**，因为它只收到数字。采集适配器现在请求 A 股前复权日线和美股 `adjust=all` 日线，并在每条 `daily_prices` 中记录调整方式；仓储禁止把新旧口径混合覆盖。学习库原有的 92 条 `adjustment=none` 日线已在用户确认后清理，需重新采集才能用于 v1 分析。其他环境若仍有旧口径数据，也应先核对并处理，不能直接混算。

## 四个指标

| 指标 | v1 定义 | 首次有值 |
| --- | --- | --- |
| MA5、MA20 | 最近 5 或 20 个已完成交易日的收盘价算术平均 | 分别在第 5、20 条日线 |
| RSI14 | 最近 14 次收盘价变化中，上涨幅度与下跌幅度分别取简单平均；`100 − 100 / (1 + 平均涨幅 / 平均跌幅)` | 第 15 条日线 |
| MACD | `DIF = EMA12 − EMA26`，`DEA = EMA9(DIF)`，本项目的 `macd` 字段取 `DIF − DEA`，不乘 2 | 第 35 条日线 |

EMA 使用 `α = 2 / (周期 + 1)`、`当前 EMA = 上一 EMA + α × (当前值 − 上一 EMA)`，并用第一条收盘价作为初值。这个选择对应 Pandas `ewm(span=..., adjust=False)` 的递推口径；实际实现不依赖 Pandas。[Pandas 窗口计算说明](https://pandas.pydata.org/docs/user_guide/window/)。

RSI 在 14 次变化全为上涨时取 100，全为下跌时取 0，全部为零时取 50。这个版本使用课程第一章的**简单平均**，不采用另一种常见的 Wilder 平滑算法。MACD 虽然从首条价格就能递推，前 34 条结果只用于预热，不对外给出 `macd` 值。指标不齐时，评分和标签均为空；第 35 条已完成日线起才评分。

## 趋势评分

从 50 分起步，每组条件至多命中一项，最后限制在 0～100 分。价格或 MACD **刚好等于**比较值时，该组加减 0 分，避免完全横盘被判为下行。

| 条件 | 变化 |
| --- | ---: |
| 收盘价 > MA20 / < MA20 / = MA20 | +18 / −12 / 0 |
| MA5 > MA20 / < MA20 / = MA20 | +14 / −8 / 0 |
| MACD > 0 / < 0 / = 0 | +8 / −8 / 0 |
| 35 ≤ RSI14 ≤ 70 | +6 |
| RSI14 > 70 | −6 |
| RSI14 < 35 | −4 |

| 最终分数 | 标签 |
| --- | --- |
| ≥ 75 | 强势上涨 |
| 60～74 | 震荡偏强 |
| 45～59 | 震荡观察 |
| < 45 | 偏弱下行 |

第一章练习给出的 `close=105、MA5=103、MA20=100、RSI=60、MACD=0.5`，按本规则得到 `50+18+14+8+6=96`，标签为“强势上涨”。35 条都收于 100 的横盘样本得到 RSI=50、MACD=0、评分 56，标签为“震荡观察”。

## 为什么先固定版本

课程资料之间存在差异：第一章的评分表与第三章代码的分值、标签阈值不同；第三章文字示例用 `MACD = DIF − DEA`，同章另一段代码却再乘以 2，且 EMA 初值不同。v1 明确采用第一章的评分分值与标签区间、第一章的简单平均 RSI，以及 `DIF − DEA` 的 MACD。**相等时记 0 分**是本项目补充的规则，已用横盘样本测试。今后若改用另一套算法，须升级规则版本并重新验收固定样本，不能悄悄覆盖旧分析结果。

## 验收方式

在项目根目录运行：

```powershell
.venv\Scripts\python -m pytest tests/test_analysis_rules.py -v
```

重点看四类样本：5 天均价、连续上涨或下跌的 RSI、35 天的 MACD 固定参考值，以及上涨、下跌、横盘三种评分。这里都是纯计算函数，所以使用普通 `def`；项目中的网络和数据库操作仍遵循全异步 I/O 规则。
